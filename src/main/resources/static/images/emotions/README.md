# Emotion image library

Generated with the built-in image_gen tool, 2026-10-28. Eight PNG atlases contain 72 illustrations. The first row contains houses, the second trees, the third people. CSS displays one of the nine tiles; originals are preserved. No runtime image generation API is called. Gemini text classification still uses the existing API quota.

EmotionImageService maps text to one of eight broad moods; these are illustration themes, not exhaustive psychological categories or diagnoses. Users may change the mood or select NONE. To extend this library, add an atlas and its nine captions in EmotionImageService. Keep captions in row-major order and matching the artwork.
